# Global City Inventory Dashboard

Static GitHub Pages package for the Global 100 city boundary indicator dashboard.

- `index.html`: bilingual public web dashboard entry, Chinese-first by default.
- `index_zh.html`: Chinese-first dashboard entry.
- `index_en.html`: English-first dashboard entry.
- `global_100_city_boundary_100km.geolibre.json`: GeoLibre Desktop project.
- `dashboard_manifest.json`: build manifest and audit summary.
- `country_boundaries_110m.geojson`: country boundary overlay for the web map.

The dashboard uses `GUB_City_100km` boundaries and visualizes matched Global 100 cities only.
